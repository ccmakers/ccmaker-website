# News updates

Each `.md` file here is one update in the **Latest News** section on the home
page. The three most recent (by `date`) are shown; older ones drop off
automatically. Delete files you no longer want to keep.

```markdown
---
title: "Fall class registration is open"
date: 2026-08-25
summary: "One or two sentences shown on the card."
link: "/events"                # optional — internal path or full https:// URL
linkText: "See the schedule"   # optional — defaults to "Read more"
pinned: false                  # optional — pinned items sort above the rest
---

Body text is optional and is not shown on the home page.
```

Files starting with `_` (like this one) are ignored by the content loader.
